The Argument
Reversible Computation Is Free · Forgetting Costs kT ln2
The gallery's axiom
∃R(t) → ∃M₀ : dS(MR,t)/dt > 0 — to reason is to burn.
Every other version asks what survives at the Mandelbrot boundary. This one strips the question to its thermodynamic core and measures the exchange rate directly.

The engine is a reversible Margolus block CA. The lattice is partitioned into 2×2 blocks; a fixed random permutation R of the sixteen block-states is, by construction, a bijection — so the automaton is exactly reversible. Run it backward and the initial configuration returns bit-for-bit. Reversible transitions cost nothing.

Set p = 0 and press REVERSE: the lattice retraces its own history to the seed, and the erased-bit meter never leaves zero.

Raise the knob p and a fraction of blocks instead pass through a collapse map C — the logical AND of the four cells — which is not injective. By Landauer's principle each erased bit must dissipate at least kT·ln2 of heat. The meter counts log₂ of how many states C just made indistinguishable; the ledger converts that to joules at 300 K.

Now press REVERSE again. The reversible machine perfectly inverts its reversible steps — but every collapse is gone for good. The recovery check reports exactly how many cells you can no longer get back. That irrecoverable count is the arrow of time, and it is precisely the heat you paid.

Skeptic — reversibility is proven, not asserted
At p = 0 the round-trip recovery check must read 0 cells lost. If it ever doesn't, the engine is not reversible and every number on this page is void. Drive p > 0 and the same check measures the bits Landauer says are unrecoverable.

What you're watching
p=0 preserves configurational entropy and is perfectly reversible. Raising p drives entropy down — information destroyed is heat dissipated. The ledger is the same quantity counted two ways: bits the machine can no longer distinguish, and joules it must shed.
